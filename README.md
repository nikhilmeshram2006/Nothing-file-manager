## About

Nothing Files is an Android file manager built around a simple idea: managing files shouldn't feel complicated.

Inspired by the visual identity of Nothing OS, the project focuses on a monochrome interface, distinctive typography, dot-matrix details, and subtle interactions.

The goal is to create a file manager that feels lightweight, intuitive, and comfortable to use every day.

## Design

- Minimal and distraction-free interface
- Monochrome colour palette with subtle red accents
- Dot-matrix-inspired visual elements
- Clean layouts and consistent typography
- Smooth transitions and thoughtful interactions
- Dark and light appearance

## Planned Features

- [x] Browse internal storage
- [x] Navigate folders and directories
- [x] View files by category
- [x] Recent files and quick access
- [x] Copy, move, rename, and delete files
- [x] Share files with other applications
- [x] Image, video, audio, and document browsing
- [x] Storage usage overview
- [x] Search files and folders
- [x] Dark and light themes

Features will be added gradually as development progresses.

## Getting Started

### Requirements

- Android Studio
- JDK compatible with the project's Gradle configuration
- Android SDK
- Git

### Clone the repository

```bash
git clone https://github.com/nikhilmeshram2006/Nothing-file-manager.git
```

Open the project in Android Studio, allow Gradle to sync, and run the application on an Android device or emulator.
